# Kapan dan untuk Apa Menggunakan Berlian

**Diperbarui:** 2026-09-09

## Waktu terbaik untuk menggunakan berlian

Waktu terbaik untuk menggunakan berlian adalah selama event Diamond Expert.
Event ini berlangsung dua minggu sekali, pada hari Sabtu dan Minggu. Anda dapat
melihat kalender untuk mengetahui apakah event tersebut berlangsung minggu ini.

Selama event ini, tingkatkan level VIP hingga VIP 13. Setelah itu, Anda tidak
perlu lagi menginvestasikan berlian pada VIP. Singkatnya, VIP 13 memungkinkan
Anda menyelesaikan event sekop sepenuhnya tanpa melakukan pembelian dengan uang
asli.

Selama Diamond Expert, Anda juga dapat membeli kontainer AP—Action Point. AP
dapat diperlukan untuk farming buku dan berpartisipasi dalam berbagai event.

Namun, sebelum mencapai VIP 13, usahakan untuk tidak menggunakan berlian kecuali
benar-benar diperlukan.

Pada saat yang sama, salah satu event berikut mungkin sedang berlangsung:

- Diamond Shop, tempat Anda dapat menemukan item yang berguna;
- Wasteland Mine, yang juga dapat menguntungkan untuk diikuti.

Namun, sebelum mencapai VIP 13, sebaiknya simpan berlian dan jangan gunakan
untuk event-event tersebut.

## Kegunaan berlian lainnya

Berikut hal-hal yang membuat saya menggunakan berlian:

- Saya membeli Directed Relocate di Mystery Shop. Item ini selalu dibutuhkan,
  dan di sana Anda dapat membelinya dengan harga diskon.
- Saya meningkatkan kelangkaan benih di Greenhouse. Membuat semua benih menjadi
  emas akan terlalu mahal bagi banyak pemain, tetapi Anda dapat menggunakan
  beberapa percobaan.
- Saya mengambil sumber daya tambahan di Supply Depot, tetapi hanya ketika ada
  tugas yang sesuai di Greenhouse.
- Sekali sehari, saya mempercepat produksi Nanoweapon Parts. Biayanya hanya 200
  berlian per hari dan memungkinkan saya memproduksi senjata tanpa berhenti.
