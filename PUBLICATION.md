# Договорённость о публикации

Эти правила применяются ко всем последующим запросам автора на публикацию
гайдов и не требуют повторного подтверждения.

## Граница публикации

Запрос «опубликовать гайд» означает:

1. оформить канонический текст и все четыре языковые версии;
2. обновить глоссарий и навигацию;
3. создать pull request и дождаться успешного завершения проверок;
4. самостоятельно объединить pull request в `main`, чтобы изменения были
   переданы в GitBook.

## Работа с авторским текстом

- Автор по умолчанию прав в отношении содержания гайда.
- Без отдельного согласования разрешены только форматирование и исправление
  грамматики.
- Смысл, советы, числа и авторская подача меняются только после явного одобрения
  автора.
- Переводы должны сохранять смысл и структуру канонического текста.

## Проверка фактов и вопросы

- Агент может проверять фактическую точность, задавать автору вопросы и давать
  советы.
- Такая проверка не останавливает публикацию: авторский текст остаётся
  источником истины.
- Вопросы, сомнения и советы существуют только в рамках сессии с агентом и не
  добавляются в текст гайда.
