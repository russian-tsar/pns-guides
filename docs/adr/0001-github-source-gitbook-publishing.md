# GitHub как источник, GitBook как публикационный слой

Гайды хранятся в публичном GitHub-репозитории как переносимый Markdown, а
GitBook Basic синхронизирует ветку `main` и остаётся единственным публичным
сайтом. Для пяти языков используются отдельные каталоги и GitBook Spaces,
объединённые в варианты одного сайта; GitHub Pages исключён, чтобы не содержать
два конкурирующих процесса публикации и не создавать дубли страниц в поиске.

GitBook-специфичная разметка не используется, поэтому публикационный слой можно
заменить без переписывания содержания. Все пять языковых версий выпускаются
одновременно, а CI блокирует неполные или структурно расходящиеся изменения.
