# Domain docs

This repository uses a single-context layout.

## Before exploring

Read:

- `CONTEXT.md` at the repository root
- ADRs in `docs/adr/` that relate to the area being explored

If these files are absent, proceed silently.

## Vocabulary

Use the canonical terms defined in `CONTEXT.md`. Avoid synonyms that the
glossary explicitly rejects.

If a necessary concept is missing, reconsider the wording or record the gap
through the domain-modeling workflow.

## Decisions

If proposed work conflicts with an existing ADR, identify the ADR and explain
why the decision should be reconsidered instead of silently overriding it.
