# PNS Guides

Многоязычные гайды по игре Puzzles & Survival.

Русская версия каждого гайда является каноническим текстом. Английская,
индонезийская, корейская и упрощённая китайская версии подготавливаются с
помощью ChatGPT и публикуются одновременно с ней.

## Языки

- [Русский](./ru/README.md)
- [English](./en/README.md)
- [Bahasa Indonesia](./id/README.md)
- [한국어](./ko/README.md)
- [简体中文](./zh-CN/README.md)

## Работа с материалами

1. Создайте отдельную ветку.
2. Измените русскую страницу и четыре языковые версии в одном pull request.
3. Используйте игровые термины из [глоссария](./GLOSSARY.md).
4. Обновите поле `updated` и видимую дату на каждой изменённой странице.
5. Запустите `python3 scripts/check_docs.py`.
6. После успешных проверок объедините pull request в `main`.

Подробные правила описаны в [руководстве по переводу](./TRANSLATION.md), а
постоянные договорённости с автором — в [договорённости о
публикации](./PUBLICATION.md).

## Публикация

Ветка `main` является источником публичного сайта GitBook. Каждый языковой
каталог подключается к отдельному GitBook Space, а пять Spaces объединяются в
один сайт как языковые варианты. GitHub Pages не используется.
